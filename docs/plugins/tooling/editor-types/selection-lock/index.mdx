# Selection Lock

Editor-only types backing [Selection Lock](../../enhancements/selection-lock.md). [FNSelectionLock](selection-lock.md) owns the lock state and applies it; [FNSelectionLockColumn](selection-lock-column.md) is the Outliner column that shows and toggles it; [FNSelectionLockMenu](selection-lock-menu.md) installs the matching actor context menu entry. Mirrors the layout of `NexusToolingEditor/Public/SelectionLock/`.
