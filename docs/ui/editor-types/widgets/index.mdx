# Widgets

Editor-only Slate widgets — built where the engine's own multibox and toolbar paths cannot be extended or styled into the shape an editor tool needs. Mirrors the layout of `NexusUIEditor/Public/Widgets/`.

Unlike the [Components](../components/index.mdx), these are native `SWidget`s rather than UMG wrappers, so they are used from C++ tooling code and never appear in a Widget Blueprint.
