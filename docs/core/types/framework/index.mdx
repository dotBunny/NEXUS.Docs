# Framework

Ready-made gameplay-framework classes for the maps that need almost none of it: a boot map, a splash screen, a front-end menu. Set [ANNullGameMode](null-game-mode.md) as a map's game mode and the player gets an [ANMenuPlayerController](menu-player-controller.md): UI input only, nothing else. Mirrors the layout of `NexusCore/Public/Framework/`.
